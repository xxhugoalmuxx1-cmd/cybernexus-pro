Guía de Hardening & Endurecimiento de Servidores

Buenas prácticas y configuraciones críticas para blindar servidores Linux/Windows contra intrusiones.

1. Endurecimiento SSH (/etc/ssh/sshd_config)

  • PermitRootLogin no
  • PasswordAuthentication no (Usar Claves SSH)
  • Port 2222 (Cambiar puerto por defecto)

2. Cortafuegos y Red (UFW / IPTables)

  • sudo ufw default deny incoming
  • sudo ufw default allow outgoing
  • sudo ufw allow 2222/tcp && sudo ufw enable
